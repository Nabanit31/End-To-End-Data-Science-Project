# 🚀 End-To-End Data Science Project

## 📌 Overview

This project demonstrates a complete **End-to-End Data Science and Machine Learning Pipeline** built using industry-standard practices. The project covers everything from data ingestion and preprocessing to model training, evaluation, experiment tracking, and deployment-ready architecture.

The primary goal of this project is to showcase how real-world machine learning systems are developed using modular, scalable, and production-oriented approaches.

# ⚙️ Workflow of the Project

## 1️⃣ Data Ingestion

* Load dataset from source
* Split train and test datasets
* Store artifacts

## 2️⃣ Data Transformation

* Handle missing values
* Perform feature engineering
* Apply preprocessing pipeline

## 3️⃣ Model Training

* Train machine learning models
* Evaluate multiple algorithms
* Select the best-performing model

## 4️⃣ Experiment Tracking

* Track experiments using MLflow
* Store metrics and parameters
* Integrate with DagsHub for remote tracking

## 5️⃣ Model Evaluation

* Analyze model performance
* Compare evaluation metrics
* Save the trained model

# 📦 Installation

## Clone the Repository

```bash
git clone https://github.com/Nabanit31/End-To-End-Data-Science-Project.git
```

## Navigate to Project Directory

```bash
cd End-To-End-Data-Science-Project
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

```bash
python app.py
```

or run the training pipeline:

```bash
python src/pipeline/train_pipeline.py
```
